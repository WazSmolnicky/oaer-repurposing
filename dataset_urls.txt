# Auxiliary resources the release reads.
#
# One link per line. Every link below was fetched and its content read back; a
# link whose content did not match its card is not listed. Access date 2026-09-27.
#
# Each line records what the release's own probe saw when the tree was assembled.
# The probe is `python3 -m oaer.console.verify`, which reports one entry per
# resource under the `live` family in verification_report.json; the status after
# the card is that entry's.
#
# Transport note: the GEO series matrix below is served over HTTPS on an NCBI FTP
# host whose TLS handshake this Python build abandons with an unexpected EOF, so
# the in-process probe reports it BLOCKED while the system HTTP client reads the
# same URL in full. The content match recorded on that line was made with the
# system client, not with the probe. Every other line is served by a host the
# probe reads directly.
#
# The private multi-centre arm is deliberately absent: the cohort is held at the
# three sites that generated it, is irreversibly anonymised there, and is never
# redistributed. What ships instead is the schema and a schema-compatible
# builder. PAIP2020 is also absent, because its download sits behind a
# click-through research-use gate (Sec. 2.2).
